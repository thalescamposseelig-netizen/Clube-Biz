# Entrega — Clube Biz MINDSET

Esta pasta reúne a landing page, os estilos, as interações demonstrativas, a documentação de produto e os assets necessários para abrir o protótipo localmente.

## Arquivos

- `index.html` — página inicial.
- `styles.css` — identidade visual e layout responsivo.
- `script.js` — navegação móvel e validação demonstrativa do formulário.
- `PROJETO-CLUBE-BIZ.md` — estratégia, arquitetura, fluxos, requisitos e pendências.
- `assets/` — logos da Biz, logos dos parceiros e fontes Pogonia usados na página.

Abra `index.html` no navegador para visualizar a página. O formulário é apenas demonstrativo: não envia nem armazena dados.
